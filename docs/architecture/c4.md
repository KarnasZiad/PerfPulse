# Architecture C4

## Niveau 1 — Contexte

```mermaid
flowchart LR
  visitor([Visiteur d'un site]) -->|navigue| site[Site client + SDK PerfPulse]
  site -->|lots d'événements| pp[PerfPulse]
  dev([Développeur / tech lead]) -->|consulte| pp
  ops([Exploitant]) -->|crée projets et jetons| pp
```

## Niveau 2 — Conteneurs

```mermaid
flowchart LR
  sdk[SDK < 5 Ko<br/>dans la page] -->|POST /v1/collect<br/>sendBeacon| ingest[Ingestion<br/>Fastify 5]
  ingest -->|XADD| stream[(Redis 7<br/>Stream pp:events)]
  ingest -->|limitation de débit| stream
  stream -->|XREADGROUP| processor[Processeur<br/>groupe de consommateurs]
  processor -->|COPY par lots| tsdb[(TimescaleDB<br/>hypertables, agrégats continus)]
  processor -->|bulkWrite| mongo[(MongoDB 8<br/>groupes d'erreurs)]
  browser([Navigateur]) --> web[Tableau de bord<br/>Vue 3 + ECharts]
  web -->|/api, cookie de session| api[API de lecture<br/>Fastify 5]
  api --> tsdb
  api --> mongo
  ingest -. projets et clés .-> tsdb
```

| Conteneur       | Responsabilité                                                                  | Mise à l'échelle             |
| --------------- | ------------------------------------------------------------------------------- | ---------------------------- |
| SDK             | Mesure passive, envoi groupé à la fermeture de la page                          | —                            |
| Ingestion       | Valide, filtre par origine, limite le débit, enrichit, écrit dans le stream     | Horizontale, sans état       |
| Redis Stream    | Tampon durable entre la réception et le stockage, absorbe les pics              | Mémoire bornée (`MAXLEN`)    |
| Processeur      | Lit par lots, écrit dans les bases, accuse réception, reprend les orphelins     | Un consommateur par instance |
| TimescaleDB     | Mesures brutes (30 j), agrégats horaires et quotidiens (400 j), projets, jetons | Verticale, compression       |
| MongoDB         | Groupes d'erreurs par empreinte, occurrences d'exemple (14 j)                   | —                            |
| API             | Requêtes du tableau de bord, cloisonnées par projet                             | Horizontale                  |
| Tableau de bord | Graphiques du p75, pages, erreurs                                               | Fichiers statiques           |

L'ingestion ne touche **aucune base** sur le chemin d'une requête : les projets et leurs origines
autorisées sont gardés en mémoire et rafraîchis toutes les 60 secondes.

## Niveau 3 — Composants du processeur

```mermaid
flowchart TB
  reader[StreamReader<br/>XREADGROUP COUNT 200] --> batch[Lot]
  claimer[Claimer<br/>XAUTOCLAIM > 60 s] --> batch
  batch --> split{Par type}
  split -->|vital| vitals[VitalsWriter<br/>bucket log, notation]
  split -->|view| views[PageViewsWriter]
  split -->|error| errors[ErrorGrouper<br/>normalisation, empreinte]
  vitals --> tsdb[(TimescaleDB)]
  views --> tsdb
  errors --> mongo[(MongoDB)]
  batch -->|succès| ack[XACK]
  batch -->|5 échecs| dead[Stream pp:events:dead]
```
